## 本轮 P0 接受条件

1. 正式页面不显示 `Sample`、`Pilot Fixture`、`Fixture`、英文测试组织名。
2. 系统名称统一为“国内 GEO 运营与交付系统”，能力主名称统一为“国内 AI 检测”。
3. 三角色首页回答当前阶段、待办、风险和下一步，并且指标有真实来源、链接、筛选与可执行空状态。
4. 账号、百度关键词、AI 拓词/用户问题、国内 AI 检测、代理商交付至少形成一个真实持久化动作闭环。
5. 未授权代理商和跨角色访问继续受控拒绝；账号投影无秘密字段。
6. Runtime SHA、Product Code SHA 与最终 Bundle 目标 SHA 明确一致。
