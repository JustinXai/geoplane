# 百度关键词人工决策闭环 V2

## 事实结论

0011 冻结结构不支持把原始导入行直接标记为“已确认”。真实关系为：

`导入记录 → 密封数据快照 → 标准化关键词 → 人工关键词组 → 审核包 → 人工决定记录`

本检查点按该关系接线，没有修改 0011，也没有用入库数量冒充确认数量。

## 已接通能力

- 导入预检结果和数据版本由现有导入路由返回并持久化。
- 操作者只能选择同一项目、同一数据快照内的标准化关键词，填写组名和分组依据后建立待审核关键词组。
- 审核包只能引用该快照中已提交的关键词组。
- 人工决定只允许“确认 / 要求修改 / 不通过”；后两项必须填写说明，且同一审核项不能重复决定。
- 工作台读取关键词组、审核包和最后一条真实决定；待处理、已确认、需要修改、未通过指标均来自数据库，并可点击筛选。
- 客户、已授权代理商和平台管理员可在各自权限范围内完成链路；未授权客户被项目授权守卫拒绝。
- 页面刷新和重新登录后从读取模型重新获取结果，不依赖浏览器临时状态。

## 验证证据

- `tests/runtime/keywords/review-service.test.ts`：快照成员约束、跨客户隔离、人工决定和不可重复决定。
- `tests/runtime/keywords/review-workspace-routes.pg.test.ts`：客户导入与整理、授权代理商提交、平台决定、未授权客户拒绝、重新登录后持久化读取。
- `tests/runtime/keywords/baidu-workspace-read-model.test.ts`：客户和项目双重范围及真实汇总。

仍未接入的百度推荐出价、竞争度、地域维度和历史重复行数量继续作为明确能力缺口展示；本检查点未生成推测值。
