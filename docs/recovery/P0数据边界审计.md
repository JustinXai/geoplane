# P0 数据边界审计

结论：**PASS**。

## 已守住的边界

- 百度需求事实只能来自带文件哈希、来源定位和观察时间的 CSV/XLSX 导入；AI 扩展不产生 `OBSERVED_DEMAND`、搜索量、出价、竞争度、趋势、流量或排名。
- Probe 原始结果按客户组织和项目存储，只允许四个启用平台与 `MANUAL_SAMPLE`；失败样本不会被解释成“未提及”。
- 自动已管理信源引用率固定为 `NOT_CALCULATED`，指标必须来自人工标注并回溯到 RawProbeResult。
- 行业规则定义、规则评估、关键词证据、拓词快照、Probe 原始结果、代理商工作流与交付记录均有数据库级只追加保护。
- 0010 没有密码、Cookie、Token 或 API Key 列；正式 API 响应剔除 `secretReference`。
- 账号平台限制为冻结的 4 个 AI 与 12 个内容平台；`secretref://` 由服务与数据库校验，发布回执由服务与 DB Trigger 校验任务范围。
- 未发现真实客户数据、真实账号秘密、历史关键词数量或 Provider 返回内容进入本轮新增文件。
