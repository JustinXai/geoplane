# 后端能力与页面映射

## 接线原则

页面只调用当前 HTTP Route、Application Service 与 Read Model。Route 仅承担认证、授权、校验、服务调用和展示 DTO 转换；业务规则不得复制到页面或 Route。没有安全读取或写入能力时，标记 `BACKEND_CAPABILITY_NOT_AVAILABLE` 并显示中文正式空状态。

| 后端能力 | 页面消费者 | 方式 | 边界 |
| --- | --- | --- | --- |
| 登录、会话与角色授权 | 三工作台入口、顶部上下文 | `CURRENT_RUNTIME` | 客户不可进入代理商/平台；代理商不可越权客户 |
| 组织、代理商、客户 | 平台总览与组织/代理商/客户管理 | `CURRENT_RUNTIME` | 只展示授权字段，不泄漏内部标识 |
| 项目 | 三角色项目页、客户总览 | `CURRENT_RUNTIME` | 按角色和当前客户过滤 |
| 客户分配 | 平台客户分配、代理商客户切换 | `CURRENT_RUNTIME` | 代理商仅见有效授权客户 |
| 邀请与账号 | 平台邀请与账号 | `CURRENT_RUNTIME` | 撤销等写操作保留审计 |
| 账户与业务审计 | 平台审计中心 | `CURRENT_RUNTIME` | 操作者与目标展示中文业务含义，隐藏 UUID/Hash |
| 企业知识与资料缺口 | 客户知识库、代理商代操作 | `CURRENT_RUNTIME` | 文件与表单真实落库，刷新/重登连续 |
| 百度关键词、拓词任务 | 三角色关键词页 | `CURRENT_RUNTIME` | Provider 保持关闭；无读取路由时不得伪造结果 |
| 用户问题与状态确认 | 客户/代理商问题页 | `CURRENT_RUNTIME` | 内部枚举由统一中文词典转换 |
| 内容任务、正文与信源 | 内容页 | `CURRENT_RUNTIME` | 来源采集仍为独立延后系统；不新增爬虫或自动引证 |
| 内容审核 | 客户/代理商审核、平台业务审核 | `CURRENT_RUNTIME` | 人工批准/退回；自动批准关闭 |
| 人工探测与结果 | 人工探测、GEO 报告 | `CURRENT_RUNTIME` | 只聚合真实人工结果，不伪造监测数据 |
| 交付与发布回执 | 交付中心、代理商交付 | `CURRENT_RUNTIME` | 默认渠道为 0；自动发布关闭 |
| Provider 状态 | 平台运营总览、系统健康 | `CURRENT_RUNTIME` | 仅显示“已关闭”等安全摘要，不显示 Key、密码、完整地址 |

## 缺口处理

- 已有服务但缺少 HTTP Route：由后端接线工作流增加最薄适配器，并补授权测试。
- 无安全 Read Model：`BACKEND_CAPABILITY_NOT_AVAILABLE`，页面不显示按钮或假数字。
- 低优先级且无能力：保留页面入口时只显示“该功能尚未开放”。
- 所有正式页面禁止导入 `_fixtures` 或硬编码演示指标。

## 冻结项

数据库迁移继续保持 `0001–0017`；本阶段不新增迁移。真实 Provider 调用、真实客户数据、自动批准、自动发布、默认发布渠道和来源自动采集均保持关闭或为零。
