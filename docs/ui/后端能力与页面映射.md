# 后端能力与页面映射

页面只调用现有 HTTP Route、Application Service 与 Read Model；服务端负责认证、授权和租户过滤。没有能力时统一标记 `BACKEND_CAPABILITY_GAP`，不显示假按钮或假数字。

## 已接入能力（21 项）

| 能力组 | 正式页面 |
| --- | --- |
| 登录、会话、角色落点与路由隔离 | 登录页、三个工作台 |
| 组织、代理商、客户与项目读取/创建 | 平台管理页、三角色总览/项目页 |
| 客户分配、邀请与审计 | 平台客户分配、邀请权限、审计中心 |
| 企业资料、知识文件、知识包确认与缺口 | 客户企业资料、代理商代操作 |
| 安全账号投影、账号登记与确认授权 | 三角色账号页；不返回秘密引用 |
| 百度关键词导入与项目概览 | 三角色关键词页 |
| 离线拓词预览、批次读取、逐条确认/删除 | 三角色 AI 拓词/关键词页 |
| 用户问题与内容方向读取/人工确认 | 客户与代理商问题/审核页 |
| 四平台人工查询选项、样本读写 | 平台、代理商、客户人工查询页 |
| 当前行业 Pack、规则与评估读取 | 平台行业规则包 |
| 代理商组合进度、阶段推进、待交付与人工交付 | 代理商总览、待办、交付中心 |
| 交付结果与发布回执读取 | 客户、代理商交付/报告页 |
| 系统就绪与 Provider 安全摘要 | 平台系统健康 |

## 已登记缺口（10 项）

1. 账号撤销授权命令。
2. 页面内凭证配置流程（敏感凭据不由前端接收）。
3. 历史导入重复数量完整读取。
4. 百度推荐出价。
5. 百度竞争度。
6. 百度地域指标。
7. 人工查询的账号关联。
8. 品牌、竞品与推荐位置人工标注持久化及完整报告指标。
9. 行业 Pack 切换动作。
10. 项目知识包列表的统一安全 Read Model。

此外，客户用户问题缺少稳定审核标识、客户文章草稿读取/修改请求仍未开放。界面对此不提供假成功。

## 冻结边界

迁移保持 `0001–0017`；Provider 关闭；自动批准关闭；自动发布关闭；默认渠道为 0；来源采集仍为 `DEFERRED_SEPARATE_SYSTEM`。
