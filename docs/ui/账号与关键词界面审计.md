# 账号与关键词界面审计

## 审计结论

**REJECT_AND_REPLAN**

底层账号、百度关键词和离线拓词 API/读取模型已经存在，平台侧也有可执行表单；但正式产品页面只实现了能力子集，未满足三角色账号中心和客户确认闭环。

## 账号中心

### 已通过

- `ACCOUNT_PLATFORM_REGISTRY` 固定 16 个平台：4 个国内 AI 平台和 12 个内容平台。
- `GET /api/accounts` 依据平台、代理商授权客户或当前客户过滤账号范围。
- `POST /api/accounts` 拒绝 `password`、`cookie`、`token`、`apiKey`、`api_key` 字段，响应移除 `secretReference`。
- 平台页 `src/app/ops/accounts/page.tsx` 只登记平台自有账号，不提供自动登录。
- 账号所有权、操作模式、凭证与健康状态已有中文映射。

### P0 缺口

1. `src/app/agency/accounts/page.tsx` 仅为“当前暂不可用”，没有授权账号读取、异常状态或项目分配。
2. `src/app/app/accounts/page.tsx` 仅为空状态；客户无法登记或撤销自己的账号授权。
3. 平台账号页只包含两组登记表单，没有账号总览、平台/代理商/客户所有权分区、授权管理、项目分配、账号健康、操作任务和操作记录。
4. 已有 `AUTHORIZE`、`ASSIGN`、`CREATE_OPERATION`、`RECORD_RESULT` API，但正式 UI 未消费这些动作。
5. 撤销授权在能力表中明确为 `BACKEND_CAPABILITY_GAP`；在该缺口解决前不能宣称客户账号授权闭环完成。

## 百度关键词

### 已通过

- 平台页通过真实项目目录选择项目，并调用真实 CSV/XLSX 导入 API。
- 导入结果展示有效、拒绝、重复数量；不会补造历史需求数据。
- `GET /api/keywords/projects/[projectId]/overview` 可读取导入批次、指纹摘要、快照和真实需求观测。
- 读取模型明确把推荐出价、竞争度、地域和历史重复数标成能力缺口，不会为 AI 扩展词伪造这些字段。

### P0 缺口

1. 正式 UI 没有消费百度关键词 Overview 读取模型：看不到导入批次、文件摘要、快照时间、原始词、标准化词、种子词和真实需求值。
2. 导入表单没有种子词、地域选择；地域后端也明确未接入。
3. 代理商百度关键词页仍为空状态，客户关键词页只读旧关键词—问题映射，不是恢复的百度关键词池。
4. 客户关键词页无法确认或删除 AI 扩展词，与冻结客户动作不符。

## AI 拓词

### 已通过

- 平台页调用真实离线预览、确认和移除 API。
- 扩展结果不展示搜索量、出价或竞争度。
- 六类组合输入与人工审核存在：前置限定、核心词、后置限定、推荐意图、问题表达、地域范围。

### P0/P1 缺口

- 冻结分类要求的品牌词、产品服务词、人群词、场景词、对比词、决策词没有完整对应；当前仅六组通用组合。
- 代理商拓词页为空状态，客户没有拓词批次读取及确认/删除界面。
- 缺少历史批次列表、问题预览批量整理和跨刷新后的页面证据。

## 边界判定

- AI 伪造百度需求：未发现。
- 明文 Secret：未发现。
- 自动登录：未发现。
- 账号所有权隔离：静态实现存在，需浏览器/HTTP 实测后才能最终 PASS。
