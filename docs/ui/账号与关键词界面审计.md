# 账号与关键词界面审计

## 判定

**PASS_WITH_CHANGES**

账号中心、百度真实需求与离线拓词已形成三角色正式界面并接入真实后端。剩余项均属于已明确登记的后端能力缺口，不是虚假 UI；浏览器视觉验收仍待人工完成。

## 账号中心

### 已通过

- 注册表固定 16 个平台：豆包、通义千问、DeepSeek、腾讯元宝及 12 个国内内容平台。
- 平台页展示安全账号总览并可登记平台自有账号。
- 代理商页读取自身及已授权客户范围账号，并可登记代理商自有账号。
- 客户页只读取客户自有账号，可登记并确认授权；平台公共账号不会进入客户列表。
- 所有权、状态、凭证、健康、风险和操作模式均转为中文展示。
- API 拒绝密码、Cookie、Token、API Key 等明文字段，响应剥离秘密引用。
- 不提供自动登录。

### 接受的后端能力缺口

- 撤销账号授权命令尚不存在，因此客户页只显示中文说明，不显示无效撤销按钮。
- 页面内凭证配置、安全授权撤销、完整项目分配和操作历史尚无相应安全能力。

这些缺口已在能力矩阵登记，界面没有伪造成功，判定不构成拒绝项。

## 百度关键词

### 已通过

- 平台、代理商、客户均可在授权项目范围调用真实 CSV/XLSX 导入。
- 正式页面展示真实导入概览、原始词、标准化词、种子来源、百度需求值与观察时间。
- AI 扩展结果明确不等同于百度真实需求，未伪造搜索量、出价、竞争度或地域值。
- 代理商项目列表按有效客户分配过滤；客户固定在自身项目范围。

### 接受的后端能力缺口

- 历史导入重复数量的完整读取、百度推荐出价、竞争度与地域维度未接入。
- 页面明确说明这些字段缺失，不做推测补齐。

## AI 拓词

- 三角色页面均接真实离线组合预览。
- 候选项必须人工确认或删除，决定写入后端并可重新读取。
- 页面不调用真实生成 Provider，不把扩展词包装为百度需求。
- 组合工具当前覆盖前置限定、核心词、后置限定、推荐意图、问题表达和地域范围；更细的品牌/产品/人群等分类可作为后续展示优化，不影响已恢复的真实人工审核闭环。

## 验证

- 账号/关键词相关定向测试包含在本轮 132 PASS 中。
- 集成本地功能验收已证明分配和写入连续性。
- 浏览器视觉和实际表单易用性仍需人工确认，因此保持 `PASS_WITH_CHANGES`。
